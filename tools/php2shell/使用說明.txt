PHP2Shell 排查工具  v1.2
檢查 PHP 是否有 CVE-2026-109618 / CVE-2026-109619
====================================================

【檔案清單】
  START.bat                  ← 點這個（會先自動解除防火牆封鎖，再開程式）
  php2shell_check.exe        ← 主程式（GUI，中文介面）
  php2shell_check_cli.exe    ← 命令列版（給工程師用）
  unlock_firewall.bat        ← 單獨解除防火牆／防毒封鎖（已含在 START.bat 裡）
  restore_firewall.bat       ← 還原：把防火牆規則和防毒排除全部取消
  使用說明.txt               ← 這份

【這是什麼】
2026 年 10 月 21 日 PHP 修補了兩顆核心漏洞（CVE-2026-109618、CVE-2026-109619，
CVSS 9.2）。這是 PHP 引擎本身的問題，不是外掛、不是 WordPress，所以任何跑 PHP
的網站都可能中。兩顆洞可以讓攻擊者在不用登入的情況下執行程式碼、或讀到別人的
記憶體內容（密碼、session、金鑰）。

【怎麼用：插上 USB 之後】
  1. 雙擊 START.bat
  2. 跳出「使用者帳戶控制」問你要不要允許 → 選「是」
     （只有第一次需要，之後不會再問）
  3. 程式自己打開

第一次跑的時候它會自動做這三件事（這就是解除封鎖的動作）：
  · 在 Windows 防火牆加一條放行規則給這支程式（對外＋對內，三個網路設定檔都放行）
  · 在 Windows Defender 加一個資料夾排除（USB 這一整個資料夾）
  · 記一個記號檔 .unlock_done，之後就不會重複動作

為什麼要這樣：Windows 防火牆常常會擋住陌生程式的連線，Defender 也會把 USB 上
沒簽章的執行檔當可疑檔案掃掉，不先放行就會出現「掃描跑不動」或「程式打不開」。

【用完要還原（重要）】
  雙擊 restore_firewall.bat，它會：
  · 刪掉加進去的那三條防火牆規則
  · 取消 Defender 對這個資料夾的排除
  · 確認規則真的不見了
  客戶的機器跑完要把這個做一次，不要留設定在人家電腦上。

【掃描怎麼進行】
按左上角「開始全面掃描（本機＋區網）」，它會自動做完：
  1. 檢查這台電腦有沒有裝 PHP、版本多少
  2. 檢查這台電腦自己開的網站服務（80 / 443 / 8080 / 8000 / 8888 / 3000 / 5000）
  3. 掃描同一個區網所有機器的 80 / 443 埠，看誰跑 PHP、版本是多少
  4. 報告自動存檔

只想查一個網址：把網址貼到中間欄位（預設已填 http://），按「檢查這個網址」。
https 的站也支援。

【怎麼看結果】
  [!] 受影響   ← 版本在這波漏洞範圍內，要立刻升級
  [OK] 安全    ← 沒偵測到 PHP，或版本已經修好
  [?] 待確認   ← 有 PHP 但版本被藏起來，要去那台機器自己下 php -v 看
  [x] 錯誤     ← 連不上（沒開、被防火牆擋）

【修補版本對照】
  PHP 8.5.x  →  升到 8.5.12 以上
  PHP 8.4.x  →  升到 8.4.27 以上
  PHP 8.3.x  →  升到 8.3.36 以上
  PHP 8.2.x  →  升到 8.2.35 以上
  PHP 8.1 及更舊（含 7.x、5.x）→ 官方已停止支援，一定要升主版本

【報告存在哪】
  跟 exe 同一個資料夾（隨身碟根目錄），檔名像
  php2shell_report_20261024_133000.txt
  按「開啟報告資料夾」就會跳過去。

【注意事項】
  · 程式只讀網頁標頭做指紋判斷，不會對任何機器發動攻擊。
  · 只掃自己或客戶的機器，別人在用的網段不要去掃。
  · 區網掃描大約 15～40 秒，看網段大小和設備反應速度。
  · 命令列版用法：
      php2shell_check_cli.exe local                只掃本機
      php2shell_check_cli.exe lan                  只掃區網
      php2shell_check_cli.exe url https://x.com/   掃單一網址
      php2shell_check_cli.exe all                  本機＋區網
  · 如果 Defender 還是跳出警告擋住執行：控制台 → Windows 安全性 → 病毒與威脅防護
    → 排除項目，把這個隨身碟的路徑加進去（或直接用 unlock_firewall.bat）。
